# SWIN-S + APB

## Cách chạy

```bash
git clone https://github.com/NgoTranNgocDuy/SWIN-S.git
cd SWIN-S
pip install torch torchvision numpy requests
```

Mở `swin_s_apb_complete.ipynb` → **Run All Cells**.  
Dataset (~333 MB) sẽ tự tải về lần đầu chạy.

> Đặt `QUICK_RUN = True` (CELL 1) để chạy nhanh trên CPU, `False` để full training trên GPU.
